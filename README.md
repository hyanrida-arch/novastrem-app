# NovaStream Android

A native Android IPTV & VOD streaming application built with Kotlin, Jetpack Compose, Android Media3 (ExoPlayer), Room Database, and Material 3 design system.

## Features
- **Live TV & EPG**: Watch live television channels with dynamic electronic program guides (EPG) and progress indicators.
- **Movies & Series (VOD)**: Stream high-definition movies and episodic series with season and episode browsing.
- **Native Media3 ExoPlayer Engine**: Robust HLS and MP4 playback with audio track management, multi-ratio scaling (Fit, Zoom, Stretch), and instant seek controls.
- **Multiple Login Methods**:
  - Quick Demo Account (instant exploration mode)
  - Xtream Codes API (Live streams, VOD, and Series endpoints)
  - M3U Playlist Parser (HTTP/HTTPS URL or local playlist)
- **Watch History & Resume**: Automatically records watch progress to resume playback anytime.
- **My List & Favorites**: Fast bookmarking for channels, movies, and series.
- **Offline Downloads Manager**: Download movies and episodes to local storage for offline playback.
- **Parental Controls**: 4-digit PIN protection for content security.
- **Material 3 Glassmorphism UI**: High-contrast dark theme with neon cyan and violet gradients.
